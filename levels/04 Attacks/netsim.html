This isn't a puzzle level — it's our own live network topology simulator, built as a separate project. It lets you build arbitrary network topologies from scratch and run real ARP spoofing and DNS poisoning attacks against them, with a live SIEM dashboard and SOC ticket queue reacting to what you do.

The panel on the left is the full application, running live — everything you do there is real, not scripted.
